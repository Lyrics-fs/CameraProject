# CameraProject UI 设计标准（专业工具型 App）

一个好的 UI 界面不是单纯“好看”，而是让用户在 **3 秒内理解这个 App 能干什么**，并在后续使用中几乎感觉不到界面的存在。

下面给出针对本项目（CameraProject：相机参数控制与测量/分析工具）的分层设计标准，可用于评审与迭代对照。

---

## 1. 信息层级：一眼就知道该看哪

### 1.1 视觉重心唯一

- 问题：预览区、滑杆、按钮、文字全部同等大小
- 好设计：预览区占据 **70% 以上**面积；控件是“配角”
- 主按钮（拍照）用高亮色；次要按钮用灰色/透明

你的 App 视觉重心应该是：取景画面 > 拍照按钮 > 滑杆数值 > 其他。

### 1.2 F 型/Z 型扫描路径

用户眼球移动习惯：

- 竖屏：从上到下，重点在顶部 1/3 和底部 1/3
- 横屏：从左到右，重点在左侧和右下

应用到你的界面：

- 顶部：状态区（错误提示、曝光量）
- 中间：预览（核心）
- 底部：滑杆区域 + 拍照按钮

---

## 2. 控件可用性：手指友好

### 2.1 点击区域最小 48dp

Android 设计规范：可点击元素最小尺寸 **48×48 dp**。

- 错误做法：拍照按钮只有 40dp
- 正确做法：至少 64dp，带触感反馈

滑杆建议：

- 滑杆轨道高度至少 4dp
- 滑块至少 20dp

文字按钮建议：

- 用 padding 扩大点击区域，不改变视觉大小

### 2.2 滑杆精确调节辅助

专业工具用户需要精确数值，而非“差不多滑一下”。

建议：

- 滑杆右侧显示当前数值（如 “ISO 400”）
- 长按滑杆弹出 ± 微调按钮（+1/3 EV）
- 双击数值区域直接输入数字

### 2.3 防误触

相机测量/控制场景中最常见误操作是滑动滑杆时误触拍照。

建议在滑杆和拍照按钮之间留出至少 **16dp 死区**。

## 3. 状态可见性：永远知道发生了什么

### 3.1 操作反馈三件套

| 操作 | 反馈方式 |
|---|---|
| 点击拍照 | 按钮缩放动画 + 触感反馈 + 快门声（可选） |
| 调节滑杆 | 实时更新数值文字 + 预览亮度变化 |
| 保存成功 | 缩略图更新 + 短暂 Toast/Snackbar |

### 3.2 不可用状态明确表达

| 状态 | 错误做法 | 正确做法 |
|---|---|---|
| 相机未就绪 | 预览黑屏，用户困惑 | 显示“相机启动中...”进度条 |
| 手动曝光不支持 | 滑杆可拖动但无效 | 滑杆置灰 + 文字提示“当前设备不支持” |
| 正在处理照片 | 按钮可再次点击 | 拍照后按钮变为进度条/禁用 |

### 3.3 状态区设计（示例）

```
┌─────────────────────────────────┐
│ ⚠️ 存储空间不足，请清理后重试  [重试] │
├─────────────────────────────────┤
│ ✓ 就绪  │ ISO 400 │ 1/125s │ BV 12.3 │
└─────────────────────────────────┘
```

## 4. 一致性：降低学习成本

### 4.1 手势一致性

| 操作 | 平台惯例 | 你的 App 应遵循 |
|---|---|---|
| 返回上一页 | 左滑边缘 / 左上角返回键 | ✅ |
| 双击预览区 | 对焦/测光 | ✅ |
| 双指缩放 | 数码变焦 | 可选 |
| 长按预览区 | 锁定曝光（AE-L） | 建议实现 |

### 4.2 文案一致性

- 同一个功能：统一命名（“拍摄/拍照/捕获”保持一致）
- 同一个参数：统一词汇（“曝光时间/快门速度”二选一并贯穿）

### 4.3 视觉一致性

- 所有按钮圆角统一（如 8dp）
- 所有卡片阴影统一（elevation 2dp）
- 图标风格统一（建议 Material Symbols）

---

## 5. 容错与可逆性：让用户敢点

### 5.1 危险操作二次确认

- 删除照片：弹窗确认
- 清除标定数据：弹窗确认
- 退出标定流程未保存：提示“是否保存当前进度”

### 5.2 可撤销操作

- 调节滑杆后提供“重置为自动值”
- 标定完成后提供“恢复默认系数”

---

## 6. 专业工具的特殊考量

专业工具型 App 与社交相机不同，核心是“测量可信度”和“读数清晰”。

### 6.1 数据密度可以更高

- 预览叠加：十字准星 + 中心测光值
- 滑杆区：显示 EV 偏移量（或可理解的差值）

### 6.2 精准优于花哨

- 避免毛玻璃、过度圆角与装饰
- 数值使用等宽字体（如 Roboto Mono）
- 深色/黑底 + 单色强调色更符合专业工具风格

### 6.3 横屏布局支持

- 横拍时滑杆从底部移到右侧
- 拍照按钮保持在右下角（单手可达区域）
